# 网站 SEO / GEO / AI 可见度自查清单

这份清单用来检查一个网站是否具备被搜索引擎和 AI 助手抓取、理解并引用的条件。这里的 GEO 指 Generative Engine Optimization（生成式引擎优化），与地理遥感无关。

自查合格，只说明网站具备被引用的条件，不等于 AI 一定会推荐你。

最后更新：2026-11-07

## 先说结论

- 地基仍然是传统的网站基本功：能被访问、读得懂、信得过、能被验证。
- Google 官方文档写明，出现在 AI Overviews 和 AI Mode 中没有额外要求，也不需要专门的 AI 文本文件或特殊标记。页面需要先被收录，并有资格以摘要形式展示。
- llms.txt 目前没有公开数据支持它能带来引用，见下文「常见误区」。

## 哪些建议有依据

| 等级 | 含义 | 例子 |
|---|---|---|
| A | 协议、标准、官方文档或法规明确规定 | robots.txt 规则、Sitemap 规范 |
| B | 搜索引擎公开指南或行业共识，对 AI 回答的影响没有量化 | 清晰导航、事实一致、内容完整 |
| C | 经验或假设，目前没有公开证据 | 某些写作句式、问答格式 |
| X | 已有数据显示目前没有效果 | llms.txt |

## 20 项通用检查

### 能被访问吗

- [ ] 重要页面都能正常打开，没有大面积死链
- [ ] robots.txt 没有误屏蔽核心页面（文件不存在不算错，服务器报错要修）
- [ ] 有 Sitemap，且里面只放能正常访问的页面
- [ ] 页面没有意外的 noindex
- [ ] 防火墙或 CDN 没有把搜索和 AI 爬虫一律拦成 403
- [ ] 证书有效，全站走 HTTPS，http 一次跳转到 https

### 读得懂吗

- [ ] 核心正文在原始 HTML 里就有，不是完全靠脚本渲染
- [ ] 每页标题不重复、有清晰的主标题；描述是完整语句，不是关键词罗列
- [ ] 导航让人和爬虫都能找到所有核心业务，栏目名一看就懂
- [ ] 服务页说清楚：是什么、适合谁、怎么做、怎么收费、有什么限制
- [ ] 首屏有一句可以被直接引用的定义

### 信得过吗

- [ ] 公司主体、联系方式在页脚和「关于」页清楚，各页写法一致
- [ ] 关键数字写明来源、时间和口径；案例说明范围，不夸大
- [ ] 有隐私政策和服务条款，并在收集信息的表单旁链接
- [ ] 文章有作者署名和发布、更新时间
- [ ] 不用无依据的绝对化说法；承诺类内容把条件、例外和补救写清楚

### 能被验证吗

- [ ] 同样的事实（名称、价格、服务范围）在各页和各语言版本一致
- [ ] 站外有官方资料可以互相印证，如企业信息库、官方账号、行业目录
- [ ] 定期用固定的一组问题，在你关心的模型里测试，记录品牌是否被提到、说得对不对
- [ ] 每次改动后复测，而不是凭感觉

## 海外站点多看这几项

- [ ] 每种语言有独立网址；各语言版本用 hreflang 互相标注，价格和条款在各版本一致
- [ ] 有隐私政策和服务条款。面向欧盟和英国访客时，Cookie 同意可以拒绝，同意前不加载非必要脚本，拒绝后页面内容仍然完整
- [ ] LinkedIn、Crunchbase、Product Hunt 等平台上的公司信息与官网一致
- [ ] 品牌名如果很通用，用「品牌名 + 品类」的固定写法，避免被同名产品淹没
- [ ] 接入 IndexNow，让 Bing 系搜索更快知道更新

## 如果你也在中国做生意

- [ ] 页脚显示 ICP 备案号并链接到官方查询页；备案主体与网站运营主体一致（是否适用请自行判断）
- [ ] 避免中国广告法限制的极限用语，引用数据时注明出处和适用期限
- [ ] 在国内多个运营商网络测速，避免依赖国内打不开的第三方资源

## 常见误区

- 「加个 llms.txt 就能被 AI 引用。」Ahrefs 在 2026 年 6 月发布的分析覆盖 137,210 个域名，其中约 3.8 万个有有效的 llms.txt，这些文件里 97% 在 2026 年 5 月没有收到任何请求；AI 检索类爬虫的请求占比约 1.1%。公开数据不支持这个说法。
- 「加了 FAQ 标记就能提升推荐。」价值在于页面上真的有清楚的问答，而不是标记本身。
- 「关键词越多越好。」现代检索看语义和事实，堆砌只会降低可读性。

## 示例：用这份清单检查我们自己的两个站

作者自己运营两个网站：面向海外的 sharehub.fun 和面向中国大陆的 ynwone.com。它们的页面在每次发布前都要通过一套自动检查，下面列出和本清单对应的做法：

| 检查方面 | sharehub.fun（海外） | ynwone.com（国内） |
|---|---|---|
| robots.txt、Sitemap | 有，发布前检查 Sitemap 与页面一一对应 | 有，同样检查 |
| AI 爬虫策略 | robots.txt 对所有爬虫放开，并逐个列出各 AI 爬虫和社交预览爬虫（均为 Allow）；发布后检查线上文件与本地逐字一致，防止被平台改写 | robots.txt 里列出各 AI 爬虫 |
| 多语言 | 中、英、西、法四种语言各有独立网址，用 hreflang 互相指向 | 仅中文 |
| IndexNow | 已接入 | 已接入 |
| 备案与合规 | 隐私政策、服务条款 | 已完成 ICP 备案 |
| llms.txt | 有，列出全部页面；按 X 级对待，不指望它带来引用 | 同左 |

这只说明两个站具备被引用的条件，不代表它们已经被 AI 推荐。两个站都还很新，我们用这份清单自己检查，也是想知道哪些做法真的有用。

## 怎么用

先自己过一遍，再把不确定的项交给工具或专业的人复核。机器可以判断「有没有」，但资质、案例和法律合规是否真实，需要人来确认。
